2. Какие персональные данные могут обрабатываться

При использовании Сайта Оператор может обрабатывать сведения, которые пользователь предоставляет самостоятельно:

  • имя;
  • номер телефона;
  • имя пользователя или контакт в Telegram;
  • адрес электронной почты;
  • адрес сайта пользователя;
  • текст обращения и содержащиеся в нём сведения;
  • иные данные, добровольно указанные пользователем при обращении.

При посещении Сайта также могут автоматически обрабатываться технические данные: IP-адрес, сведения о браузере и устройстве, дата и время посещения, посещённые страницы, источник перехода, cookie-файлы и сведения о взаимодействии с элементами Сайта.

Оператор не ставит целью обработку специальных категорий персональных данных, включая сведения о здоровье, политических взглядах, религиозных убеждениях и интимной жизни. Пользователю не следует указывать такие сведения в свободных полях форм без необходимости.

3. Цели обработки

Персональные данные обрабатываются для:

  • обработки обращений пользователей;
  • связи с пользователем по его запросу;
  • предварительной оценки задачи;
  • подготовки коммерческого предложения;
  • заключения и исполнения договоров;
  • оказания услуг и взаимодействия с заказчиками;
  • технической поддержки;
  • обеспечения работы и безопасности Сайта;
  • анализа использования Сайта и улучшения его содержания;
  • ведения статистики посещаемости.

Персональные данные не используются для рекламных рассылок без отдельного предварительного согласия пользователя.

4. Правовые основания обработки

Оператор осуществляет обработку персональных данных на основании Федерального закона № 152-ФЗ «О персональных данных», согласия субъекта персональных данных, а также в случаях, когда обработка необходима для заключения или исполнения договора по инициативе субъекта персональных данных.

Пользователь предоставляет согласие добровольно путём совершения соответствующего действия в интерфейсе Сайта.

5. Способы обработки

Обработка может осуществляться как с использованием средств автоматизации, так и без их использования.

Оператор может совершать с персональными данными следующие действия: сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, передачу лицам, привлекаемым для технического обеспечения обработки, блокирование и удаление.

6. Срок обработки

Персональные данные обрабатываются только в течение срока, необходимого для достижения целей обработки, исполнения договора или выполнения требований законодательства.

После достижения целей обработки данные удаляются или обезличиваются, если законодательство не требует их дальнейшего хранения.

Согласие пользователя может быть отозвано в порядке, указанном в настоящей Политике.

7. Хранение персональных данных

При сборе персональных данных граждан Российской Федерации посредством Сайта Оператор обеспечивает выполнение требований законодательства Российской Федерации к записи, систематизации, накоплению, хранению, уточнению и извлечению данных с использованием баз данных, расположенных на территории Российской Федерации.

С 1 июля 2025 года требования к российской локализации первичного хранения стали строже: использование зарубежной базы для первоначального сбора российских персональных данных в общем случае не допускается.

8. Передача третьим лицам

Оператор не продаёт персональные данные пользователей.

Данные могут передаваться лицам, которые обеспечивают работу Сайта и выполнение обращения пользователя, если такая передача необходима и осуществляется на законном основании.

Для анализа посещаемости Сайта может использоваться сервис Яндекс.Метрика, предоставляемый ООО «ЯНДЕКС».

Информация об использовании средств веб-аналитики дополнительно приведена в Политике использования cookie.

9. Трансграничная передача

Оператор может осуществлять трансграничную передачу персональных данных только при соблюдении требований законодательства Российской Федерации, включая требования статьи 12 Федерального закона № 152-ФЗ.

10. Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия, блокирования, уничтожения и иных неправомерных действий.

Доступ к персональным данным предоставляется только в объёме, необходимом для достижения целей обработки.

Пользователь вправе:

  • получать сведения об обработке своих персональных данных;
  • требовать уточнения неточных данных;
  • требовать прекращения обработки в предусмотренных законом случаях;
  • отозвать ранее предоставленное согласие;
  • требовать удаления персональных данных при наличии законных оснований;
  • обращаться в Роскомнадзор или суд для защиты своих прав.

Для реализации этих прав пользователь может написать на:

a.lambert@pr-up.ru

Согласие на обработку персональных данных может быть отозвано путём направления соответствующего заявления на:
