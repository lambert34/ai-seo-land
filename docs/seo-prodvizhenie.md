# Страница SEO-продвижения

Адрес после публикации: https://lambert-digital.ru/seo-prodvizhenie/
Исходник: `seo-prodvizhenie/index.html`. Стили: `css/seo-prodvizhenie.css`.

Страница использует общие шапку, подвал, кнопки, карточки, мобильное меню и механизм cookie. Английского перевода нет: переключатель ведёт на существующую английскую главную, без `hreflang="en"`. Ссылки на услугу добавлены в русское меню, карточку SEO на главной, карточку SEO-аудита и раздел SEO-кейсов. Генератор статей сохраняет пункт меню при пересборке; содержимое существующих статей не изменено. Cloudflare-сборка включает новый каталог и проверяет наличие его HTML.

## Предложение и контент

- SEO-аудит сайта — **от 10 000 ₽**, разово.
- Комплексное SEO-продвижение — **от 35 000 ₽**, в месяц.

Десять разделов, шесть вопросов FAQ, четыре кейса из `/cases/#seo-cases`. Формулировки результатов скопированы из существующих кейсов: рост видимости не переименован в рост трафика. Кейс о первом клиенте через месяц не опубликован. Показатель «100+» относится к участию в проектах в разных ролях.

Будущих SEO-статей в репозитории нет. Блок материалов содержит обычный текст без ссылок на неопубликованные страницы. Связанных опубликованных SEO-статей в каталоге нет; ссылки в несвязанные статьи не добавлены.

## Настройка Яндекс.Метрики вручную

Используется существующий счётчик **109997768**. Второй счётчик не добавлен. Согласие обрабатывает `js/cookie-consent.js`, общие цели — `js/main.js`. Все цели блокируются без согласия на аналитику, даже если `ym` существует. Согласие работает и при недоступном localStorage в пределах текущего посещения.

В интерфейсе Метрики создайте цели типа «JavaScript-событие»:

| Идентификатор | Событие |
| --- | --- |
| `seo_click_consultation` | Клик по кнопке обсуждения, заказа аудита, расчёта продвижения или получения оценки по email |
| `seo_click_telegram` | Клик по ссылке Telegram на SEO-странице, включая подвал |
| `seo_form_submit` | Зарезервировано для будущей формы; сейчас **не отправляется**, поскольку формы нет |

При клике сохраняются соответствующие общие цели, включая `lead_click`; каждое имя отправляется один раз на действие. `lead_click` обозначает намерение связаться, а не доставленную заявку. Переход из карточки цены на страницу услуги не считается лидом.

Отдельно создайте цель:

- Название: **SEO — просмотр страницы**.
- Тип: **Посещение страниц**.
- Условие: **URL содержит `/seo-prodvizhenie/`**.

Цели в интерфейсе Метрики автоматически не создавались. Настройка `seo_form_submit` не означает, что отправка формы уже реализована.

## Проверки и публикация

Используйте Node.js 22.16.0 из `.node-version`. Без изменения рабочих HTML можно создать временную копию проекта вне репозитория и выполнить в ней:

```bash
npm ci --no-audit --no-fund
node --test tests/seo.test.mjs
npm run test:articles
npm run test:i18n
npm run audit:english
npm run build:cloudflare
```

Тесты статей и сборка перегенерируют HTML и sitemap, поэтому запускайте их в временной копии, если не намерены обновлять сгенерированные страницы. Проверку i18n выполняйте до появления `dist`, поскольку она рекурсивно ищет HTML. Для ручного просмотра: `python3 -m http.server 8000 --directory dist` из каталога сборки.

GitHub Actions `.github/workflows/pages.yml` развёртывает сайт при push в `main`. Локальный коммит сам по себе не запускает публикацию. После отправки коммита проверьте успешный workflow и HTTP 200 целевой страницы. Для Cloudflare используется `npm run build:cloudflare` с каталогом `dist`.

После публикации:

1. Откройте https://lambert-digital.ru/seo-prodvizhenie/ и проверьте HTTP 200, canonical, `index, follow`, контакты и отображение. Проверьте https://lambert-digital.ru/sitemap.xml: адрес включён. `robots.txt` разрешает обход.
2. В Google Search Console выберите ресурс `lambert-digital.ru`, откройте «Проверка URL», вставьте **https://lambert-digital.ru/seo-prodvizhenie/**, проверьте опубликованную страницу и нажмите «Запросить индексирование». В разделе Sitemaps отправьте или проверьте `https://lambert-digital.ru/sitemap.xml`.
3. В Яндекс Вебмастере выберите сайт, откройте «Индексирование → Переобход страниц», добавьте **https://lambert-digital.ru/seo-prodvizhenie/** и отправьте на переобход. В «Файлы Sitemap» проверьте или добавьте `https://lambert-digital.ru/sitemap.xml`.
4. Создайте цели Метрики по таблице выше и проверьте их в режиме отладки с принятыми аналитическими cookie. Повторите проверку с отказом: целей быть не должно.

Запросы индексирования не отправлялись. Проверка внешнего production-адреса и списка запусков GitHub Actions из этой среды заблокирована сетевым прокси (HTTP 403); локальные проверки не подтверждают deployment или индексацию.

- 24 теста прошли: 17 статей, 2 i18n и 5 новых проверок SEO-страницы/аналитики.
- Аудит английской версии: 13 страниц, без ошибок. Сборка Cloudflare: 7 статей, новый раздел включён в `dist`; локальный HTTP 200.
- Chromium: ширины 320, 375, 768, 1024, 1440 px. Проверены геометрия без горизонтального обрезания, цены, меню, FAQ с клавиатуры, фокус и переход CTA к контактам. Снимки находятся вне репозитория в `/workspace/.environment-setup/seo-validation/`.
- Аналитика проверена с перехваченным транспортом, без отправки тестовых данных в production: согласие отсутствует / только необходимые / принято / localStorage недоступен; дубли целей отсутствуют, инициализация счётчика однократная. Контент и внутренние HTTP-ссылки проверены без JavaScript.
- Регрессия: проверены меню главной на 375 × 667 px, контекстная ссылка в кейсах и существующая форма лендинга с имитацией неуспешного/успешного ответа (без реальной передачи данных). Меню получило ограничение высоты и прокрутку для коротких экранов.
- Доставка письма, звонка или сообщения внешними сервисами не проверялась. Публикация и индексация не подтверждены; сетевой прокси заблокировал запросы production-адреса и GitHub Actions API.
